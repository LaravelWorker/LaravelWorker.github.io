# komiagin.dev

Персональный лендинг. Статика, без сборки и зависимостей — только шрифты с Google Fonts.

## Что в папке

| Файл | Зачем |
|---|---|
| `index.html` | Вся страница: разметка, стили, скрипт фона. Единственный файл, который нужно править |
| `og.png` | Картинка 1200×630 для превью ссылки в Telegram, LinkedIn, почте |
| `icon-512.png` | Иконка для ярлыка на телефоне |
| `robots.txt` | Разрешает индексацию, указывает путь к карте сайта |
| `sitemap.xml` | Карта сайта для Google Search Console и Яндекс.Вебмастера |
| `CNAME` | Домен для GitHub Pages. Если хостинг не GitHub — файл можно удалить |
| `.nojekyll` | Отключает обработку Jekyll на GitHub Pages |

## Как выложить

1. Загрузите всё содержимое папки в корень репозитория (не саму папку — именно файлы из неё).
2. Settings → Pages → Source: Deploy from a branch, ветка `main`, папка `/ (root)`.
3. Custom domain: `komiagin.dev`, дождаться проверки, включить Enforce HTTPS.
4. Скрытые файлы `.nojekyll` и `CNAME` через веб-интерфейс GitHub не перетащить — залейте их через git либо создайте вручную кнопкой Add file → Create new file.

Если хостинг не GitHub Pages — просто положите файлы в корень сайта, `CNAME` и `.nojekyll` удалите.

## После выкладки

- Отправьте `https://komiagin.dev` самому себе в Telegram и проверьте, что развернулась карточка с картинкой. Telegram кеширует превью надолго, поэтому проверять лучше до рассылки.
- Добавьте сайт в Google Search Console и Яндекс.Вебмастер, отправьте `sitemap.xml`. Без этого новый домен индексируется неделями.
- Проверьте разметку через Google Rich Results Test.

## Что стоит доделать

- **Кейсы.** Блок с проектами убран, потому что был пустым. Сейчас страница описывает навыки, но ничего не доказывает. Один-два разобранных проекта (задача → что сделал → результат с цифрой) добавят больше, чем любые правки дизайна.
- **GitHub.** Это единственное доказательство на странице. В `LaravelWorker` стоит держать хотя бы пару репозиториев с внятным README.
- **Статьи.** Разбор интеграции с криптобиржевым API или идемпотентности в биллинге закрывает ту же дыру, что и кейсы, но без нарушения NDA, и заодно приносит поисковый трафик.

## Правки относительно вашей версии

- `Veact` → `React`; `Anagular` убран (его нет ни в блоке «Стек», ни в резюме).
- В «Локация» возвращено гражданство Грузии и России — для работодателя из СНГ это снимает вопрос об оформлении нерезидента.
- Страница приведена к одной формулировке: раньше в шапке значился fullstack, а в заголовке вкладки, блоке «Итого» и подвале — backend.
