Разработка ботов для MAX

Чат-боты для мессенджера MAX под ключ · общий бэкенд с Telegram

Делаю ботов для MAX, которые продают подписки, принимают оплату и открывают доступ к платному контенту. Если у вас уже есть Telegram-бот, бот для MAX работает на том же бэкенде: одна база пользователей, одни подписки, одна админ-панель.

В рабочем проекте бот для MAX появился, когда часть аудитории заказчика ушла из Telegram. Канал доставки контента сохранили, а продажа и продление подписок так и идут без ручных операций.

Какие задачи бизнеса закрывает бот

пять сценариев
01

Продажа подписок и платный контент

Бот оформляет подписку, принимает оплату, продлевает её и открывает доступ к закрытым материалам. Когда подписка заканчивается, доступ закрывается сам.

подписки · автопродление · доступ к контенту
02

Приём оплаты

Встроенной оплаты в Bot API MAX нет, поэтому платёж идёт через провайдера: бот выдаёт ссылку, провайдер присылает уведомление на сервер, бот подтверждает оплату и выдаёт доступ. Чеки по 54-ФЗ — в той же интеграции.

платёжный провайдер · вебхуки · 54-ФЗ
Подробнее про оплату в боте →
03

Заявки и уведомления

Сбор заявок, напоминания клиентам, уведомления сотрудникам. Данные попадают в админ-панель или в вашу CRM по API.

заявки · рассылки · интеграция с CRM
04

Второй канал рядом с Telegram

Бот для MAX подключается к существующему бэкенду. Логика и данные общие, отличается только слой работы с API мессенджера. Аудиторию, которая ушла из Telegram, не нужно заводить в новую систему.

общий бэкенд · одна база · одна админка
05

Мини-приложение внутри MAX

Когда кнопок и сообщений мало — каталог, личный кабинет, форма записи — к боту подключается веб-приложение, которое открывается прямо в мессенджере. Мини-приложение проходит отдельную модерацию платформы.

веб-приложение · Vue / React

Частые вопросы

про ботов в MAX
Кто может завести бота в MAX?

По правилам платформы — юрлица, ИП и самозанятые, которые являются резидентами РФ, после верификации профиля. Бота регистрирует заказчик на свою организацию, я подключаюсь по токену. Модерация занимает до 48 часов по рабочим дням.

Можно ли принимать оплату в боте MAX?

Да, через платёжного провайдера. Бот формирует ссылку на оплату, после оплаты провайдер присылает уведомление на сервер, и бот открывает доступ. Встроенных платёжных методов, как Stars в Telegram, в Bot API MAX нет.

У меня уже есть бот в Telegram. Его придётся писать заново?

Нет. Логика, пользователи и подписки живут в общем бэкенде, для MAX добавляется свой слой работы с API мессенджера. Так устроен проект из кейса: админ-панель, Telegram-бот и бот для MAX работают на одном бэкенде.

Сколько стоит бот для MAX?

Цена зависит от сценариев, числа интеграций и того, есть ли уже бэкенд. После короткого созвона присылаю оценку по этапам.

На чём пишете ботов?

Бэкенд на PHP и Laravel или на Node.js и TypeScript, база PostgreSQL, Redis для очередей и кеша, админ-панель на Vue.

Что происходит после запуска?

Сервис можно оставить на сопровождении: мониторинг работоспособности, исправления, доработки под новые сценарии и изменения API мессенджера.
