Оборудование заказчика распределено по разным сервисам и пулам. Простой отдельной машины замечали случайно — бывало, устройство не работало неделями. Задача

что было

Оборудование распределено по разным сервисам и пулам. Простой отдельной машины замечали случайно — были случаи, когда устройство не работало неделями. Требовалось видеть состояние всего парка и узнавать о сбое сразу.

Решение

четыре части
01

Сбор телеметрии

Данные о каждом устройстве собираются по API нескольких сервисов и пулов — до 10 000 устройств с опросом раз в минуту. Лимиты частоты, повторы и отказы внешних API учтены в опросе.

PHP · Laravel · API сервисов и пулов
02

Двухуровневое хранение метрик

Оперативные метрики живут в Redis, в PostgreSQL пишутся суточные агрегаты. Минутный опрос парка такого размера не раздувает базу, а по каждому устройству остаётся история метрик за весь период наблюдения.

Redis · PostgreSQL
03

Пороги и алерты

Контроль uptime, температуры и просадок производительности. Пороги настраиваются, при выходе за них уведомление уходит в Telegram и на почту.

Telegram Bot API · email

Частые вопросы

про мониторинг майнеров
Как узнать, что майнер перестал работать?

Система опрашивает API сервисов и пулов раз в минуту и сверяет показатели с порогами. Если устройство встало, перегрелось или просело по производительности, уведомление уходит в Telegram и на почту. В этом проекте простой машины виден через 3 минуты.

Что отслеживает мониторинг?

Uptime, температуру и просадки производительности каждого устройства. Пороги настраиваются, при выходе за них приходит уведомление.

Оборудование подключено к разным пулам. Можно ли видеть всё в одном месте?

Да. В проекте телеметрия собирается по API нескольких сервисов и пулов и сводится в одну систему: состояние всего парка видно в одном месте.

Не разрастётся ли база при опросе раз в минуту?

Нет. Оперативные метрики хранятся в Redis, а в PostgreSQL пишутся суточные агрегаты. Поэтому минутный опрос 10 000 устройств не раздувает базу, а история по каждому устройству остаётся за весь период наблюдения.

Сколько стоит такой мониторинг для своей фермы?

Цена зависит от числа источников данных, устройств и нужных уведомлений. После короткого созвона присылаю оценку по этапам.
