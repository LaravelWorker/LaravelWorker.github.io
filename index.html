Биллинг и движение средств

Расчёт и списание, финансовые лимиты, распределение средств между участниками, история операций. Проектирую так, чтобы баланс сходился и операцию можно было объяснить постфактум.

Интеграции с внешними API

Платёжные провайдеры и криптобиржи: подпись запросов, лимиты частоты, повторы, сверка расхождений. Отдельно закладываю поведение на случай, когда внешний сервис отвечает не так, как обещал в документации.

REST / JSON API · вебхуки · криптобиржи
03

Telegram-боты и Mini Apps

Полный цикл: бот, веб-приложение внутри Telegram, авторизация через initData, платежи и админка. Подходит там, где нужен продукт без отдельного мобильного приложения.

Node.js · TypeScript · Vue / React
04

Инфраструктура и сопровождение

Разворачиваю и держу сервис сам: Linux, Docker, окружения, деплой, мониторинг работоспособности, масштабирование. Плюс код-ревью и наставничество для младших разработчиков.

Docker · Ubuntu · Nginx · Cloudflare
