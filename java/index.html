Чем занимается Java-разработчик

коротко

Java-разработчик пишет серверную часть и приложения на Java: API для сайтов и мобильных приложений, бизнес-логику, работу с базой данных, интеграции с внешними системами и фоновую обработку. Java выбирают там, где код должен жить долго и предсказуемо работать под нагрузкой: финтех, логистика, крупные внутренние системы компаний. Отдельная большая область — Android: заметная часть приложений и библиотек написана на Java, и их поддерживают наравне с кодом на Kotlin.

Как разработчик на Java я делаю бэкенд на Spring и Android-приложения. В работе это чаще всего API, интеграции и данные — и вопросы вокруг них: что будет, если внешний сервис ответил ошибкой, как не списать деньги дважды, как не потерять событие при перезапуске.

Бэкенд и Android-приложение для курьерской службы

Пример задачи и архитектуры, а не проект из портфолио
Задача
Диспетчер раздаёт заказы курьерам по телефону, а статусы доставки узнаёт из переписки.
Как собрать
Бэкенд на Spring Boot: заказы, курьеры, статусы, REST API с авторизацией по токенам. Android-приложение курьера на Java: список заказов, смена статуса, фото при доставке, push-уведомление о новом заказе. Если связь пропала, статусы копятся в приложении и уходят на сервер, когда сеть вернётся.
Что получит заказчик
Диспетчер видит статус каждого заказа без звонков, курьер получает заказы в приложении.
Java · Spring Boot · PostgreSQL · Android · Firebase Cloud Messaging
Типовое решение

Сервис сверки оплат с учётной системой

Пример задачи и архитектуры, а не проект из портфолио
Задача
Компания принимает оплату онлайн, а бухгалтерия сверяет платежи с заказами вручную в конце месяца.
Как собрать
Сервис на Spring Boot принимает вебхуки платёжного провайдера, проверяет подпись и сохраняет событие с уникальным ключом — повторный вебхук не создаёт дубль. Фоновая задача обновляет статус заказа в учётной системе через её API, при ошибке повторяет с паузой. Раз в день — сверка с отчётом провайдера, расхождения приходят в Telegram.
Что получит заказчик
Оплаченные заказы закрываются сами, расхождения видны в тот же день, а не в конце месяца.

Частые вопросы

про Java
Чем занимается Java-разработчик?

Пишет серверную часть и приложения на Java: API для сайта и мобильного приложения, бизнес-логику, работу с базой данных, интеграции с внешними системами, фоновую обработку. Java выбирают для систем, которые должны долго жить и предсказуемо работать под нагрузкой. Ещё одна большая область — Android: заметная часть приложений написана на Java.

Можно нанять вас на проект, а не в штат?

Да. Работаю по договору с ИП — на отдельный проект, этап или на постоянную доработку. В штат тоже рассматриваю — удалённо, в гибридном формате или в офисе. На удалёнке рабочий день совпадает с московским.

Java или Kotlin для Android?

Для новых Android-приложений Google рекомендует Kotlin: код короче, а часть ошибок с null ловится ещё при компиляции. Java остаётся рабочим вариантом, особенно если приложение уже на ней написано. Оба языка уживаются в одном проекте, поэтому существующий код на Java можно дорабатывать и переводить на Kotlin постепенно.

Spring Boot или Node.js для бэкенда?

Пишу на обоих. Spring Boot хорош для систем со сложной бизнес-логикой и транзакциями, где важны строгие типы и долгий срок жизни кода. Node.js быстрее на старте и удобен для API, ботов и сервисов, которые много общаются с внешними API. Выбор зависит от задачи, нагрузки и того, кто будет поддерживать код.

Можно ли подключиться к готовому проекту на Java?

Да. Разбираю чужой код, исправляю ошибки, расширяю функционал, делаю ревью. Начинаю с того, что поднимаю проект локально и проверяю, как он собирается и тестируется.

Сколько стоит разработка на Java?

Цена зависит от объёма, числа интеграций и того, есть ли уже бэкенд, приложение или дизайн. После короткого созвона присылаю оценку по этапам.
