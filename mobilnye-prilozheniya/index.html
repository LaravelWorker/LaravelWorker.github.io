Разработка мобильных приложений

iOS и Android · React Native · Swift / Kotlin · PWA

Делаю мобильные приложения кроссплатформенно на React Native, нативно на Swift и Kotlin или как PWA — в зависимости от задачи и бюджета. Бэкенд, API, оплату и админ-панель пишу сам, поэтому приложение и сервер развиваются вместе.

До старта помогаю выбрать формат. Иногда задачу дешевле закрыть PWA или Telegram Mini App, чем выпускать приложение в сторы.

Типовые решения

как это может выглядеть
Типовое решение

Приложение записи для сети студий

Пример задачи и архитектуры, а не проект из портфолио
Задача
Сеть студий принимает записи по телефону и в мессенджерах, клиенты забывают о визитах.
Как собрать
Приложение на React Native для iOS и Android: расписание, запись, предоплата через платёжного провайдера, push-напоминания. API на Laravel, админка расписания и мастеров на Vue.
Что получит заказчик
Запись без звонков, меньше неявок, расписание всех студий в одной системе.
React Native · TypeScript · Laravel · PostgreSQL · Vue
Типовое решение

PWA для выездных сотрудников

Пример задачи и архитектуры, а не проект из портфолио
Задача
Курьеры или мастера получают задания в мессенджере и отчитываются фотографиями в чат.
Как собрать
PWA ставится на экран телефона и работает без сети: список заданий, фотоотчёт, отметка о выполнении. Данные синхронизируются, когда появляется связь. Диспетчер видит статусы в веб-кабинете.
Что получит заказчик
Отчёты в одном месте, без публикации в сторах и без обучения сотрудников.
PWA · React · Node.js · PostgreSQL

Частые вопросы

про мобильные приложения
Сколько стоит разработка мобильного приложения?

Зависит от числа экранов, платформ и интеграций и от того, нужен ли бэкенд. После созвона присылаю оценку по этапам. Часто разумно начать с MVP на React Native или PWA.

React Native или нативная разработка?

React Native — когда нужны обе платформы и важны сроки и бюджет. Нативно на Swift и Kotlin — когда важны производительность, работа с камерой и датчиками или сложная графика.

Публикуете приложение в App Store и Google Play?

Да: готовлю сборки и прохожу модерацию. Аккаунты разработчика в сторах оформляются на заказчика, чтобы приложение принадлежало ему.

Можно ли обойтись без приложения в сторах?

Часто да. PWA ставится на экран телефона из браузера, а Telegram Mini App открывается внутри мессенджера. Для внутренних инструментов и сервисов с аудиторией в Telegram это быстрее и дешевле.

Бэкенд тоже делаете?

Да: API на Laravel, Node.js или Python, база, авторизация, оплата и админ-панель.
