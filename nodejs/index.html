Интеграция с торговым API Bybit и REST API для фронтенда, автоматические stop-loss и take-profit. Котировки поставлял отдельный Python-сервис через Redis, на стороне бэкенда — дедупликация запросов с кешированием ответов. Торговая логика закрыта автотестами. Продукт не нашёл места на рынке, но серверная часть была собрана целиком и работала.

Частые вопросы

про Node.js
Node.js или PHP для бэкенда?

Пишу на обоих. Node.js удобен там, где много одновременных соединений и работы с внешними API. Laravel быстрее даёт готовые очереди, авторизацию и админку для типового веб-сервиса. Выбор зависит от задачи и от того, кто будет поддерживать код.

Пишете на чистом JavaScript?

Новые проекты — на TypeScript: типы ловят часть ошибок до запуска и упрощают поддержку. С существующим кодом на JavaScript тоже работаю.

Можно ли подключиться к готовому проекту?

Да. Разбираю чужой код, восстанавливаю и расширяю функционал, делаю ревью.
