Частые вопросы

про Python
FastAPI или Django?

Django — когда нужен сайт или сервис с админкой, пользователями и контентом: многое есть из коробки. FastAPI — для API и микросервисов: он лёгкий, асинхронный и сам генерирует документацию OpenAPI.

Python или PHP для веб-сервиса?

Оба языка подходят для веба. Python удобнее, если рядом обработка данных или машинное обучение, PHP с Laravel — если нужен типовой веб-сервис быстро. Подробно — в статье «PHP или Python».

Можно ли написать бота для MAX на Python?

Да. Bot API MAX — обычный HTTP API с вебхуками и long polling, с ним работает любой язык.

Сколько стоит разработка на Python?
