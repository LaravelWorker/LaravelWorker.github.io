Частые вопросы

про React и Next.js
Когда нужен Next.js, а когда хватит React?

Next.js — когда страницы должны индексироваться и быстро открываться с первого захода: сайт, каталог, блог. React SPA — для кабинетов и админок за логином, где индексация не нужна.

Next.js или Nuxt?

Это похожие решения на разных библиотеках: Next.js построен на React, Nuxt — на Vue. Выбирать стоит по тому, на чём команда будет поддерживать проект. Сам делаю такие проекты на Next.js.

Бэкенд тоже делаете?

Да: API на Laravel, Node.js или Python, оплата, уведомления и админ-панель. Фронтенд и сервер проектирую вместе.

Сколько стоит сайт на Next.js?

Цена зависит от объёма, числа интеграций и того, есть ли уже бэкенд или дизайн. После короткого созвона присылаю оценку по этапам.
