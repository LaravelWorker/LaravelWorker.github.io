Чем занимается TypeScript-разработчик

коротко

TypeScript — это JavaScript с типами: компилятор ещё до запуска проверяет, что функции получают и возвращают данные нужной формы. TypeScript-разработчик пишет на нём серверную часть на Node.js, интерфейсы на React или Vue, а часто и то и другое.

Больше всего типы дают на стыке частей. Когда сервер и фронтенд описывают запросы и ответы одними и теми же типами, изменение в API сразу видно во всём проекте: редактор подсвечивает каждое место, которое нужно поправить. Поэтому я веду TypeScript через весь стек, а не только в одной его половине.

Частые вопросы

про TypeScript
Чем занимается TypeScript-разработчик?

Пишет на TypeScript — JavaScript с типами — серверную часть на Node.js, интерфейсы на React или Vue, а часто и то и другое. Типы проверяются до запуска кода, поэтому часть ошибок ловится при сборке, а не у пользователя.

Можно нанять вас на проект, а не в штат?

Да. Работаю по договору с ИП — на отдельный проект, этап или на постоянную доработку. В штат тоже рассматриваю — удалённо, в гибридном формате или в офисе. На удалёнке рабочий день совпадает с московским.

Зачем TypeScript, если есть JavaScript?

Типы описывают, какие данные принимает и возвращает каждая функция и каждый запрос к API. Редактор подсказывает и подсвечивает ошибки, переименование и рефакторинг становятся безопаснее, а новому человеку в команде проще разобраться в коде. Для короткого скрипта это лишнее, для продукта, который будут развивать годами, — нет.

Можно перевести наш проект с JavaScript на TypeScript?

Да, постепенно и без остановки разработки. TypeScript работает рядом с JavaScript в одном проекте, поэтому сначала типизируются API и общие модели, а остальной код переводится модуль за модулем.

Пишете и бэкенд, и фронтенд?

Да. Бэкенд на Node.js, фронтенд на React, Next.js или Vue 3 — с общими типами запросов и ответов. Могу вести обе части или подключиться к одной из них в вашей команде.

Сколько стоит разработка на TypeScript?

Цена зависит от объёма, числа интеграций и того, есть ли уже код, который нужно переводить на TypeScript. После короткого созвона присылаю оценку по этапам.
